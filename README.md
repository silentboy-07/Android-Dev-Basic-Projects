# 📱 Android Basic Projects

This repository contains a collection of **beginner-friendly Android projects** built to practice core development concepts like UI design, logic building, and user interaction.

---

## 🚀 Projects Included

### 🧮 BMI Calculator

* Calculates Body Mass Index based on user input
* Simple UI with input fields and result display
* Concepts: User Input, Basic Calculations, UI Design

---

### 📇 Contact Layout

* Static contact UI design
* Displays user details like name, phone, and email
* Concepts: Layout Design, UI Components, Styling

---

### 👋 First App (Hello World)

* Basic Android app displaying "Hello World"
* Entry-level project to understand app structure
* Concepts: Activity Lifecycle, Basic UI

---

### ➗ Simple Calculator App

* Performs basic arithmetic operations (Add, Subtract, Multiply, Divide)
* Interactive UI with buttons
* Concepts: Event Handling, Logic Building

---

### ❌⭕ Tic Tac Toe Game

* Classic 2-player game
* Tracks game state and winner logic
* Concepts: Game Logic, State Management, UI Interaction

---

## 🛠️ Tech Stack

* Java / Kotlin (depending on your projects)
* Android Studio
* XML (UI Design)
